# Cars Exploratory Data Analysis (EDA)

Exploratory Data Analysis of used-car listings using the Vehicle Dataset from CarDekho.

## Project Files

- `cars_eda_project.py` — Python script for data analysis and visualization.
- `requirements.txt` — Required Python libraries.
- `CAR DETAILS FROM CAR DEKHO.csv` — Main dataset used by the script.
- `car_data.csv` — Additional car dataset.
- `Car details v3.csv` — Additional car dataset.
- `car details v4.csv` — Additional car dataset.

## Features

- Dataset exploration and descriptive statistics
- Missing-value and duplicate checks
- Data cleaning and outlier analysis
- Data visualization using Matplotlib and Seaborn
- Correlation analysis and key findings

## Installation and Usage

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the analysis:

```bash
python cars_eda_project.py
```
